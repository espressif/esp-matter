# Bridge Examples

The examples below demonstrate the Matter bridge functionality.
A Matter bridge is a way in which non-Matter devices (e.g. Zigbee, BLE-Mesh, ESP-NOW, RainMaker) can be accessed using Matter.

The [Matter: Bridge for Non-Matter Devices](https://developer.espressif.com/blog/matter-bridge-for-non-matter-devices)
blog explains the core idea and technical details of the Matter bridge.

| Example | Description |
|---------|-------------|
| [blemesh_bridge](blemesh_bridge/) | Bridges BLE Mesh devices to Matter |
| [bridge_cli](bridge_cli/) | Console-driven bridge for adding/removing bridged devices at runtime |
| [esp-now_bridge_light](esp-now_bridge_light/) | Bridges ESP-NOW devices (e.g. lights) to Matter |
| [esp_rainmaker_bridge](esp_rainmaker_bridge/) | Bridges ESP RainMaker devices to Matter |
| [zigbee_bridge](zigbee_bridge/) | Bridges Zigbee devices to Matter |

See each example's README for build and usage instructions.
